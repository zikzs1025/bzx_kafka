## 测试环境

| 项 | 值 |
|---|---|
| 操作系统 | Windows 11 10.0 (amd64) |
| CPU 核心 | 18 |
| JDK | 1.8.0_503 |
| JVM 最大堆 | 7195 MB |
| Kafka | spring-kafka-test 嵌入式 broker（单节点，3 分区） |
| FTP | MockFtpServer（loopback TCP，真实 FTP 协议，虚拟文件系统） |
| 单文件滚动阈值 | 50000 行 |

| 场景二：持续压力（50 万条） | 500,000 | 55,109 | 21.90 | 12 | 0 |

> 所有场景均校验：备份行数 == 生产条数、每行 31 列、单文件 <= 50000 行、FTP 远端文件数与字节数 == 本地备份。
